早期版本曾在 C03 跳过开场订单详情、C01 索要上游没有的独立实付字段、C09 多问具体钟点、C12 被另一单的暂缓拦截。首次联测中顾客改口后的旧确认被拒绝，但型号活动资料漏查，另一次撤回钟点没有同步解除等待。修订涉及对应通用业务规则。每个版本、题号及条件采集一次，逐项 JSON 保留了修订前记录。

实际采集 39 个开发及合并对话位置（含早期修订），模型往返 217 次，桥接返回 2,836,507 个 token，累计请求耗时 4564.2 秒。并发请求耗时相加，不能作为整批墙钟耗时或直连 API 账单。
