# 原服务器转发维护

长实验使用已有 SSH 配置中的远程转发。网络断开时，本地连接可能已退出，而服务器旧连接仍占用端口；直接重新连接会失败。

`scripts/keep_ssh_forward.py` 仅维护连接。它不启动、重采、评分或修改实验，不修改模型入口、模型、业务预算和冻结工作树。服务器需要支持进程句柄的 Linux 和 Python。

使用前先检查，检查连接不会创建转发：

```text
python scripts/keep_ssh_forward.py --alias 已有主机别名 --state 私有目录/检查.json --stop-file 私有目录/检查.停止 --check
```

正式维护时去掉 `--check`，使用另一份状态文件。沿用 SSH 配置现有转发，不在脚本中保存主机地址或凭证。状态与锁文件必须放在私有运行目录。结束时创建指定停止标记；脚本会在下一次心跳后结束，并尝试释放自己的服务器连接。

每次连接记录服务器 SSH 会话进程号及启动标识。重连前核对账户、进程用途及启动标识，并持有进程句柄后清理，避免进程号复用造成误操作。身份不符时拒绝清理；网络不可用时保留原身份等待恢复。相同状态文件使用排他锁，防止两个维护器互相清理。

已在原服务器通过六项测试：合法连接清理、进程号复用拒绝、其他服务拒绝、已消失连接、输入校验、清理连接不创建转发。已从本机到原服务器完成真实连接及安全释放检查。
