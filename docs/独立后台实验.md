# 单次实验独立后台运行

实验协调器本来就在服务器独立运行。新增服务器守护脚本只检查这一个实验：原协调器存活时不干预；明确的502、503或连接超时可在原网络恢复后从未完成位置恢复。每个位置最多自动恢复三次；业务零分不重采、非传输异常转为需人工检查。完成198个评分与99次整理后调用完整报告核验器，把脱敏报告写入结果目录的“脱敏结果”，随后停止。

本机后台入口维护已有SSH转发并检查服务器完成标记。已有转发使用排他锁保护，不中断正在运行的模型请求；旧维护器退出后后台入口接管。服务器全部完成且报告核验成功时，本机写停止标记并结束本轮转发维护。客户端日志及状态留在私有运行目录，不进入Git。

入口为scripts/official_memory_watchdog.py与scripts/official_memory_local_guard.py。具体服务器路径和本机SSH别名由启动参数提供。服务器“后台停止”标记停止守护，但不终止已运行的实验；本机停止标记停止本轮网络维护。

本机必须开机且不休眠，校园VPN与原代理必须可用；不要求用户一直停留在这段聊天里。后台进程不能保证关机、系统重启、VPN失效或模型服务长期不可用时仍能运行，也不能替用户完成重新登录。遇到非传输异常或同位置恢复超过三次，保留状态待人工检查。

六项服务器测试验证了传输错误识别、业务零分保留、仅未评分位置恢复、旧日志错误排除、核验异常不重跑、现有协调锁保护。业务冻结提交仍为3c526dc111720e439618f397e10ab3c9fcbd517f，守护不会修改模型、提示词、预算或经验正文。
